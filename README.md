# whois-blog

A personal blog platform built with Next.js 14, TypeScript, Tailwind CSS, Prisma, and NextAuth.js.

## Setup

1. Copy `.env.example` to `.env` and fill in the values.
2. Install dependencies: `pnpm install`
3. Run migrations: `pnpm db:migrate`
4. Seed admin user: `pnpm db:seed`
5. Start dev server: `pnpm dev`

## Testing

```bash
pnpm test
```
